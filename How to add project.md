 
# 📘 Codeyatri Project Submission Guide  
_Add your project to the Codeyatri GitHub Organization_

---

## 🛠 Purpose

Codeyatri is a community-driven GitHub organization. Members can submit their projects to be hosted under the official Codeyatri org. If your project is accepted, it gets:

- Visibility among tech community peers  
- Official backing from Codeyatri  
- Future support if it has startup/product potential  

---

## 📩 How to Submit Your Project (Member Guide)

### ✅ Requirements (Before Submitting)
- ✔️ A **GitHub username**
- ✔️ A **project name**
- ✔️ A **short description**
- ✔️ A list of **technologies used**
- ✔️ A full and well-written **`README.md` file** (mandatory)

> ❗ Submissions **without a README.md** will **not be reviewed.**

---

### 🧾 Step-by-Step Instructions

1. **Go to the Request Repo**  
   Visit: `https://github.com/Codeyatri/request-project`

2. **Click on the ‘Issues’ tab**

3. **Click on ‘New Issue’**

4. **Select the Issue Template**  
   Choose: `🚀 Request to Add Project`

5. **Fill Out the Template**  
   You’ll be asked to provide:
   - Project Name  
   - Description  
   - Tech Stack  
   - GitHub Repo Link (if hosted)  
   - Your GitHub Username  
   - Full `README.md` content

6. **Submit the Issue**

---

## ⏳ What Happens Next?

Once your issue is submitted:

1. **Codeyatri team reviews** the submission  
2. If edits are needed, you’ll be asked to update the issue  
3. On approval:
   - A **new repo** is created in Codeyatri GitHub org  
   - You’re added as a **collaborator with Write access**
4. You push your project code to that repo
5. You’re now part of the **Codeyatri Project Showcase**

---

## 🚀 Bonus: Product-Level Projects

If your project shows real potential (innovation, utility, scalability), Codeyatri will help:

- Launch it as a real product  
- Guide you in branding and marketing  
- Possibly turn it into a **startup** with you  

---

## 🧠 Questions?

Raise an issue in the `request-project` repo or contact a core team member.


---

## 📥 After Approval – What You Need to Do

Once your issue is approved by the Codeyatri team:

1. **We will send you a collaborator invite** to the new GitHub repository created under the Codeyatri organization.
2. You will receive an **email notification** and also see an invite on your GitHub dashboard.
3. **Accept the invitation** to gain write access to your assigned project repo.
4. After accepting, **clone the repo** and push your full project code along with the required `README.md`.
5. **Only after accepting the invitation** and pushing your code, your project will officially be considered a part of Codeyatri.

> 🛑 Projects without accepted collaborator invites or missing README.md files will not be maintained or listed under Codeyatri.
